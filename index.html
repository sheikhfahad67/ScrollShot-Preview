Questions

Why does ScrollShot ask to access all sites?

Many pages, such as course players and web apps, keep their long content inside an embedded frame from another site. To scroll that frame, ScrollShot needs access to it. The access is used only after you start a capture, and nothing is read, stored or sent anywhere.

Which pages can't be captured?

Chrome does not let any extension run on chrome:// pages or on the Chrome Web Store. ScrollShot can't capture those, so its buttons are greyed out there with a short message. Google Sheets is supported only with Visible area, because its grid can't be scrolled like a normal web page. For pages ScrollShot can't capture, use Chrome's own tool: open DevTools, press Ctrl+Shift+P and choose “Capture full size screenshot”.

How long a page can it capture?

Long pages work, up to about 40 screens. If a page is longer, ScrollShot captures the first 40 screens and tells you. If an image would be taller than about 16,000 pixels, it is scaled down slightly to fit the limit Chrome sets for images.

Where do I report a problem or ask for a feature?

Open an issue on the support page. If you can, tell us the website address and what you expected to see.
